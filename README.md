# MOBA-FIT — privacy policy

The published privacy policy for **MOBA-FIT**, a multiplayer VR game for Meta Horizon devices.

Served at <https://tcrosmandsi.github.io/mobafit-privacy/> via GitHub Pages, which is the URL given
to Meta's Data Use Checkup. It lives in its own public repository because the game's own repository
is private and GitHub Pages cannot serve from a private repo without a paid plan.

`index.html` is the whole site. It is written from the game's source rather than from a template, so
if the game's data handling changes, this page changes with it.
